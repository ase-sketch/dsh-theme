feat(M6): Deepy 素材流水线 + host 素材路由

T1 素材流水线（scripts/build-deepy.mjs，378 行，零 npm 依赖）：
- 自解 PNG（IHDR/IDAT inflate/反滤波）→ 预乘 alpha 的面积加权降采样（260px→64px，4.0625 倍）→ 自编码（固定 filter 0 + deflate，无时间戳，逐字节可复现）
- 产出 assets/deepy/：8 态 PNG + deepy.json（契约格式 cols/frameMs/displayPx/states）
- 四条守卫：源图尺寸、产出尺寸、非空格数=帧数、manifest 原子落盘（失败即不留半成品）

T2 host 素材路由（host/index.js +84/-4）：
- GET /api/dsh-theme/deepy/<name>，kind:'prefix'——框架无参数化路由，exact 是 pathname 严格相等
- resolveDeepyAsset 纯函数：只解码一次（双解码会被 %252e 绕过）+ 白名单正则 + path.resolve 两道防线
- 非法/越界/不存在一律 404（响应逐字节不可区分），非 GET/HEAD → 405

- 负控制：去掉校验后 ..%2f..%2fhost%2findex.js 能读到 host 源码（证明校验承重）；再叠双解码则 %252f 也 LEAK（证明"只解码一次"承重）
